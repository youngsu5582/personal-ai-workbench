## 결정
- 범위는 기준 + 테스트. convention-gate 확장은 다음으로 미룬다
- API 경로는 Spring 컨텍스트 없이 애노테이션으로 모은다. `const val` 경로는 컴파일 때 애노테이션 값으로 박혀 문자열로 읽힌다. 쿼리 파라미터 · 본문 필드는 보지 않는다
- 기준(관례)은 사용자가, 테스트 구현은 Claude 가
- 남의 이름 목록은 지금 읽는 쪽이 이 테스트뿐이라 테스트 안에 둔다. convention-gate 도 읽게 되면 conventions.json 으로 옮긴다
- 컬럼은 마이그레이션 SQL 이 아니라 jOOQ 가 만든 현재 스키마에 대조한다 — 지운 컬럼도 옛 마이그레이션에는 남는다
