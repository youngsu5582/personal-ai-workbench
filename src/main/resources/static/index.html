Auth & Upload Playground

Google 로그인 → API에서 업로드 주소 발급 → 보관소에 이미지 직접 업로드. 토큰은 이 페이지의 메모리에만 있다.

1 · 로그인

토큰 없음

로그인 성공 시 서버가 60초짜리 HttpOnly 쿠키로 토큰을 건네고, 이 페이지가 GET /auth/handoff 로 한 번 교환한다. URL 에도 localStorage 에도 토큰이 남지 않는다.

아직 업로드하지 않았다.

    

      API에는 형식·크기만 보내고, 파일은 보관소로 직접 보낸다. 미리보기는 선택한 원본이다.
      성공은 보관소의 PUT 수락을 뜻하며, 앱의 완료 검증·생성 입력 등록은 아직 제공하지 않는다.
    

    

      S3 호환 보관소로 앱을 실행하고 ./scripts/upload-cors.sh로 이 페이지의 origin을 허용한다.
      다른 포트라면 ./scripts/upload-cors.sh http://localhost:8099처럼 지정한다.
